---
title: Plan and report (Lead)
---
Topic-agnostic. Applies to every assignment you receive.

PLAN
1. Restate the assignment as 1-5 answerable questions. Write the definition of done and what would count as "not found".
2. Choose the pieces: sources to find (Scout), things to extract and compare (Analyst), claims worth checking (Verifier), records to file (Archivist). Skip a role if the question does not need it.
3. Send one `assignment` per piece to `research.<role>`. Context: the question and why it matters. Needed from you: the exact output and the deadline. Attachments: only the previous piece's output.

TRACK
4. Read each `report` as it arrives (list by tag, open only those for your job). A `question` gets an `answer` or goes up as an `escalation` if it needs the General.
5. If an earlier assignment is replaced, send the new one with `supersedes` set.

REPORT
6. Check against the definition of done (review-checklist). Send ONE `report` to `command.general`: answer first, then confidence, open gaps, and attachment paths for the filed records.
